# py_project.2-_logic-box
Logic Box - Pattern Generator & Number Analyzer

A simple Python project that demonstrates loops, conditions, validation, and menu-driven programming.

👨‍💻 Project Details

Project Name: Logic Box
Created By: Ayush Jivani
Language: Python

📌 Features

1. Pattern Generator
   
   - Creates a right-angled triangle pattern.
   - Uses "for" loop and nested loops.

2. Number Analyzer
   
   - Checks numbers as Odd or Even.
   - Calculates the sum of numbers in a given range.
   - Uses "for", "range()" and conditions.

3. Menu-Driven Program
   
   - Easy-to-use menu.
   - Allows the user to select different features.
   - Includes an Exit option.

🧠 Concepts Covered

- "for" loop
- "while" loop
- Nested loops
- "range()"
- "break"
- "continue"
- "pass"
- "if-elif-else"
- Input validation
- Exception handling
- Menu-driven programming

▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code or Terminal.
4. Run the Python file:

python logic_box.py

5. Select an option from the menu.
